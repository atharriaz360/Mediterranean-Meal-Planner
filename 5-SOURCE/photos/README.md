# Food photos (optional)

`python3 build.py --sync` embeds every `.jpg` in this folder into the app, the hosted copy and the demo, matched by file name. Dishes without a photo keep their drawn illustration. Files in `_unused/` are ignored.

**Format:** `.jpg`, 4:3, about **800×600**, quality ~70–80 (under ~100 KB each, so the app stays light).
**Rights:** only photos you made yourself (including your own AI images) or that you have a commercial licence to include in a product you sell. Stock licences such as Unsplash/Pexels do not allow this.

| File name | Used for (current demo recipes) |
|---|---|
| `herobowl.jpg` | Home hero photo (in use) |
| `stirfry.jpg` | Chicken Stir Fry |
| `salad.jpg` | Mediterranean Bowl, Mediterranean Wrap |
| `pancakes.jpg` | Banana Pancakes |
| `pasta.jpg` | Creamy Garlic Pasta, Veggie Pasta |
| `chickensalad.jpg` | Grilled Chicken Bowl, Grilled Chicken Salad |
| `salmon.jpg` | Salmon & Quinoa (a version is in `_unused/`) |
| `lentil.jpg` | Lentil Soup |
| `oats.jpg` | Overnight Oats, Greek Yogurt & Berries |

Use one style for all of them (same plate, light and angle) — mixing photos and drawings on the same screen looks inconsistent, which is why only the hero photo is used now.
